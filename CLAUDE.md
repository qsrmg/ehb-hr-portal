# Project rules

## Language

All user-facing text must be in proper, professional British English: buttons, labels,
headings, error and success messages, emails, PDFs (pay slips, letters), notifications,
settings, landing page, and docs (README, DEMO.md, DECISIONS.md).

- Correct spelling and grammar; full sentences for messages.
- Sentence case for buttons and headings (e.g. "Apply for leave").
- Error messages say what went wrong and how to fix it.
- Use the same terms everywhere: Line Manager, Head of Department (HOD), HR, Finance,
  Admin, Management, leave, attendance, pay slip, expense claim.
- Commit messages in clear English.
- No Roman Urdu or informal words in the app.
